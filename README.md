# PowerBI-Project
Interactive Power BI dashboard analyzing sales performance, profitability, customer segments, and regional trends using the Sample Sales dataset.
📊 Sales Analysis Dashboard – Power BI
Project Overview

This project is an interactive Power BI Sales Analysis Dashboard developed to analyze sales performance, profitability, customer segments, product categories, and regional trends. The dashboard helps businesses monitor key performance indicators and make data-driven decisions through clear and interactive visualizations.

Data Source

Dataset: Sample Sales Dataset (CSV)

The dataset contains sales transaction records with information such as:

Order Date
Customer Name
Segment
Region
Category & Sub-Category
Sales
Quantity
Discount
Profit
Shipping Details

1. Sales Overview
Total Sales
Total Profit
Total Orders
Total Quantity Sold
Sales Trend Analysis
2. Product Performance Analysis
Sales by Category
Sales by Sub-Category
Top Performing Products
Profit Contribution by Product
3. Customer & Segment Analysis
Sales by Customer Segment
Customer Purchase Patterns
Segment-wise Profitability
4. Regional Analysis
Sales by Region
Profit by Region
Geographic Performance Comparison
5. Shipping & Delivery Analysis
Ship Mode Distribution
Delivery Performance
Shipment Trends
Key Insights Gained
Consumer segment generated the highest sales contribution.
Office Supplies and Technology categories were major revenue drivers.
Sales performance varied across regions, highlighting growth opportunities.
Higher discounts often reduced profitability.
Certain product categories consistently delivered higher profits than others.
Shipping preferences influenced order distribution and delivery performance.
